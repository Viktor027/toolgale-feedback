# ToolGale — feedback

Free browser tools for ID and visa photos: **[toolgale.top](https://toolgale.top)**

Every tool runs entirely in your browser. Photos are never uploaded to any server, there are no accounts, no limits and no watermarks.

| Tool | What it does |
|---|---|
| [Resize photo to 1x1 inch](https://toolgale.top/resize-photo-to-1x1/) | Philippine ID standard, 300×300 or 600×600 px, print-ready DPI |
| [Resize photo to 2x2 inches](https://toolgale.top/resize-photo-to-2x2/) | US passport and visa standard, 600×600 px at 300 DPI |
| [Resize photo to 600x600 pixels](https://toolgale.top/resize-photo-to-600x600/) | DV lottery / DS-160, JPEG kept under 240 KB automatically |
| [Resize photo to 35x45 mm](https://toolgale.top/resize-photo-to-35x45/) | UK, Schengen and most European passports; UK online 900×1200 px |
| [Compress photo to 50 KB](https://toolgale.top/compress-photo-to-50kb/) | Targets 20 / 50 / 100 / 200 KB for portal upload limits |

## Found a bug, or want a tool?

[Open an issue](https://github.com/Viktor027/toolgale-feedback/issues/new) — include the tool page, your browser, and what you expected. Photos are processed locally, so please never attach a personal document photo to an issue; a description is enough.
